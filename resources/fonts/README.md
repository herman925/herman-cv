# Chapter transition fonts

Unmodified Latin WOFF2 subsets from Google Fonts:

- Fraunces, normal 600, optical size 144 (Google Fonts v38).
- Space Grotesk, normal 500 (Google Fonts v22).

The accompanying OFL files contain their copyright and licence notices.
These small local faces are preloaded and used under separate CSS family names
by the chapter transition, so the page's later Google Fonts stylesheet cannot
replace its typography mid-navigation. Ordinary page typography is unchanged.
